# 🗞️ AI News Summariser

Fetches latest India news and summarises 
each article using Google Gemini AI.

## Features
- Real-time India news
- AI powered summaries
- Save articles to database
- Clean web interface

## Built With
- Python
- Streamlit
- Gemini AI
- NewsAPI
- Supabase
